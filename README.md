# Ground Crew South

BRIK Creative project 04. Separate repo. Folder name: `ground-crew-south`.

Ground Crew South places local people on storage, line, and storm work. Lessons can be free. The paid product is a seat.

## SAMPLE warning

Every seat and trainee in this app is SAMPLE seed. Not a live hiring hall. Not a placement claim. Do not store a Social Security number. This is not an online school, not a union hall, and not a national job board.

## Run

```
npm install
npm run dev
```

## Build

```
npm run build
```

Static output lands in `dist/`. `vite.config` base is `/ground-crew-south/`. React Router basename is `/ground-crew-south`. See `DEPLOY.md` to attach that path on brucknerdemo.com without touching the vault.

## Stack

Vite + React + TypeScript + Tailwind CSS + React Router. Seed JSON only. No paid APIs. No login.
